# Kassim Umar — Developer Portfolio

A personal developer portfolio built with HTML, CSS, and JavaScript.

The portfolio introduces my background, technical interests, experience,
projects, and contact information.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Dark and light theme toggle
- Mobile navigation menu
- Smooth scrolling between sections
- Experience timeline
- Technical skills section
- Project details modal
- GitHub, LinkedIn, and email links
- Automatically updated footer year

## Technologies

- HTML5
- CSS3
- JavaScript

## Featured Project

### FixIt GH

FixIt GH is a mobile application project currently in development.

The project focuses on helping people find and book artisans for services
they need. Development is ongoing, and features may change as the application
improves.

## Run Locally

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.

You can also use the Live Server extension in Visual Studio Code to preview
the website while developing.
